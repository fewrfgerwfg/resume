## 07 自我评价

我习惯先问一句「这个数字要支撑什么决策」，再决定怎么取数、怎么建模——数据是手段，不是目的。

财经院校的训练让我看得懂业务口径和财务口径，计算机方向的课程让我能自己把数据搬到台面上；中间那段「翻译」的工作，是我最愿意并且已经练了两年的部分。

在校期间保持了每周阅读官方文档、复盘一个开源数据集分析的习惯。期待在一个真正依赖数据做决策的团队里，从打杂做起但不止于打杂。
